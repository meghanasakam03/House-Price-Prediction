# 🏠 House Price Prediction

An end-to-end Machine Learning application that predicts house prices based on property features.

## 🚀 Live Application

[Click here to access the Streamlit application](https://house-price-prediction-megha.streamlit.app/)

## 🎯 Problem Statement

Predict house prices using numerical and categorical property features through a Machine Learning pipeline.

## 📊 Input Features

- Area
- Bedrooms
- Bathrooms
- Floors
- Year Built
- Location
- Condition
- Garage

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
- GitHub

## ⚙️ Data Preprocessing

- SimpleImputer
- StandardScaler
- OneHotEncoder
- ColumnTransformer
- ML Pipeline

## 🤖 Machine Learning Algorithm

Linear Regression

## 📁 Project Files

- `app.py` — Streamlit frontend
- `house_price_pipeline.pkl` — Trained ML pipeline
- `requirements.txt` — Required dependencies
- Jupyter Notebook — Model training and evaluation
- CSV file — House price dataset

## 💻 Run Locally

Install the required dependencies:

`pip install -r requirements.txt`

Run the application:

`streamlit run app.py`

## 🌐 Deployment

Deployed using Streamlit Community Cloud.
